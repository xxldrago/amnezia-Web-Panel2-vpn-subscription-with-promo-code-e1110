# 🎁 Реферальная система VPN сервиса

## 📋 Обзор

Полноценная реферальная система для вашего VPN сервиса. Работает как независимый модуль, не требует изменений в основных моделях пользователя и продолжает работать при обновлении основного кода приложения.

## ✨ Возможности

### Для пользователей:
- **Персональный реферальный код** - уникальный 8-значный код для каждого пользователя
- **Реферальная ссылка** - автоматическая генерация ссылки вида `https://yoursite.com/register?ref=ABC12345`
- **Двусторонние бонусы**:
  - Новый пользователь получает **100₽** при первом пополнении от 100₽
  - Пригласивший получает **100₽** при первом пополнении реферала
  - **25% комиссия** с каждого последующего пополнения реферала

### Статистика в реальном времени:
- 👥 Приглашено пользователей
- 💳 Сделали первое пополнение
- ✅ Активных рефералов
- 📈 Конверсия в %
- 💰 Заработано всего (₽)
- 📅 Заработано за последний месяц (₽)

### Автоматизация:
- Автоматическое сохранение реферального кода из URL при регистрации
- Cookie-трекинг рефералов (30 дней)
- Автообновление статистики каждые 30 секунд
- Кэширование статистики для быстродействия

## 🚀 Быстрая интеграция

### Шаг 1: Добавить модуль в app.py

```python
from referral_system import setup_referral_system, on_user_register, on_user_deposit

# Инициализация реферальной системы
setup_referral_system(app)

# В настройках приложения укажите базовый URL
app.config['BASE_URL'] = 'https://yoursite.com'
```

### Шаг 2: Интеграция с регистрацией пользователей

В вашем обработчике регистрации добавьте вызов после успешной регистрации:

```python
@app.route('/register', methods=['POST'])
def register():
    # ... ваш код регистрации ...
    
    # После создания пользователя:
    user_id = str(new_user.id)  # ID нового пользователя
    on_user_register(user_id)
    
    return redirect(url_for('dashboard'))
```

### Шаг 3: Интеграция с пополнением счета

В вашем обработчике пополнения добавьте вызов после успешного платежа:

```python
@app.route('/deposit', methods=['POST'])
def deposit():
    user_id = str(current_user.id)
    amount = float(request.form['amount'])
    
    # ... ваш код обработки платежа ...
    
    # После успешного пополнения:
    result = on_user_deposit(user_id, amount)
    
    if result.get('success'):
        flash(f"Бонус начислен: {result['bonus_amount']}₽", "success")
    
    return redirect(url_for('dashboard'))
```

### Шаг 4: Добавить страницу реферальной программы

### Шаг 5: Добавить ссылку в личный кабинет


## 📊 API Endpoints

Все endpoints доступны через `/api/referral/`:

### GET /api/referral/info
Получить полную информацию о реферальной системе пользователя.

**Ответ:**
```json
{
  "referral_code": "ABC12345",
  "referral_link": "https://yoursite.com/register?ref=ABC12345",
  "referred_by": "XYZ98765",
  "stats": {
    "total_invited": 10,
    "first_deposit_count": 5,
    "active_referrals_count": 5,
    "conversion": 50.0,
    "total_earned": 1500.0,
    "month_earned": 350.0
  },
  "bonus_info": {
    "new_user_bonus": 100,
    "inviter_first_bonus": 100,
    "commission_percent": 25,
    "min_deposit": 100
  }
}
```

### GET /api/referral/stats
Получить статистику пользователя.

**Ответ:**
```json
{
  "total_invited": 10,
  "first_deposit_count": 5,
  "active_referrals_count": 5,
  "conversion": 50.0,
  "total_earned": 1500.0,
  "month_earned": 350.0
}
```

### POST /api/referral/process_deposit
Обработать пополнение для начисления реферальных бонусов.

**Запрос:**
```json
{
  "user_id": "12345",
  "amount": 500
}
```

**Ответ:**
```json
{
  "success": true,
  "bonus_amount": 125.0,
  "new_balance": 1625.0
}
```

### POST /api/referral/apply
Применить реферальный код при регистрации.

**Запрос:**
```json
{
  "user_id": "12345",
  "referral_code": "ABC12345"
}
```

**Ответ:**
```json
{
  "success": true,
  "message": "Referral applied"
}
```

## 🔧 Конфигурация

Настройки можно изменить в начале файла `referral_system.py`:

```python
REFERRAL_BONUS_NEW_USER = 100        # Бонус новому пользователю (₽)
REFERRAL_BONUS_INVITER_FIRST = 100   # Бонус пригласившему за первое пополнение (₽)
REFERRAL_COMMISSION_PERCENT = 0.25   # Комиссия с последующих пополнений (25%)
MIN_DEPOSIT_FOR_BONUS = 100          # Минимальное пополнение для бонуса (₽)
```

## 💾 Хранение данных

Модуль использует отдельную SQLite базу данных для устойчивости к обновлениям:

- **Путь:** `data/referral_system.db`
- **Таблицы:**
  - `referral_users` - пользователи реферальной системы
  - `referral_transactions` - история транзакций
  - `referral_stats_cache` - кэш статистики

Данные сохраняются независимо от основной базы данных приложения.

## 🔐 Безопасность

- Уникальные реферальные коды генерируются через SHA-256 хеширование
- Cookie с реферальным кодом защищены флагами `httponly` и `samesite='Lax'`
- Проверка на повторную привязку к рефералу
- Защита от накрутки статистики

## 🔄 Сценарии использования

### Сценарий 1: Регистрация по реферальной ссылке
1. Пользователь A переходит по ссылке `https://yoursite.com/register?ref=ABC12345`
2. Код автоматически сохраняется в сессию
3. Пользователь регистрируется
4. Система автоматически привязывает его к пользователю с кодом ABC12345
5. При первом пополнении от 100₽:
   - Новый пользователь получает 100₽
   - Пользователь ABC12345 получает 100₽

### Сценарий 2: Повторные пополнения
1. Реферал пополняет счет на 500₽
2. Пригласивший получает 500 * 25% = 125₽
3. Статистика обновляется автоматически

### Сценарий 3: Просмотр статистики
1. Пользователь заходит в раздел "Реферальная программа"
2. Видит свой код и ссылку
3. Видит полную статистику
4. Может скопировать код/ссылку или поделиться

## 🛠️ Troubleshooting

### Реферальный код не применяется
- Проверьте что код существует в базе `referral_users`
- Убедитесь что пользователь еще не привязан к другому рефералу
- Проверьте логи приложения

### Бонусы не начисляются
- Убедитесь что `on_user_deposit()` вызывается после успешного платежа
- Проверьте что сумма пополнения >= `MIN_DEPOSIT_FOR_BONUS`
- Проверьте что у пользователя есть реферал (`referred_by` не NULL)

### Статистика не обновляется
- Проверьте права доступа к базе данных `data/referral_system.db`
- Убедитесь что API endpoint `/api/referral/stats` доступен
- Проверьте консоль браузера на ошибки JavaScript
